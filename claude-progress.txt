KEY DECISIONS
-------------
- SQLite + aiosqlite (no ORM, no Postgres) — right for a class project MVP
- No auth — skipped for v1
- Static mount AFTER API routers so /api/* always wins
- Claude model: claude-sonnet-4-20250514 (speed + cost balance)
- Vibe matcher returns structured JSON: {query_interpretation, matches: [{dj_id, score, reasoning}]}
- JSON fields (genres, vibe_keywords, tech_rider, availability) stored as TEXT in SQLite,
  parsed by Pydantic @field_validator on read
- Image URLs for DJs/venues point to external CDN URLs embedded in the original HTML

KNOWN ISSUES / LIMITATIONS
---------------------------
- ANTHROPIC_API_KEY is empty in .env — AI vibe matching returns 503 without it.
  All other pages (discovery, profile, booking) work without the key.
- nocturne.db is gitignored — Render will auto-create it on first deploy (this is fine;
  seed.py runs automatically via lifespan)
- Render free tier spins down after 15 min inactivity — first request after sleep takes ~30s
- No authentication, no payment processing — intentionally out of scope for MVP
